## こんにちは

Webアプリケーションの開発を中心に、実装・既存コードの調査・改修を行っています。  

PHP / Laravelを中心とした実務経験があり、React / TypeScriptやPythonを用いた開発にも取り組んでいます。  

## 得意なこと  

- **実装・改修**：既存のコードや構造を把握し、必要な機能を実装する  
- **調査・問題解決**：不具合の原因調査や、担当範囲外のコードの解析・改修  
- **可読性を意識した設計**：責務の分割や、データ構造の整理を重視  
- **自動化**：手作業で行っていた確認作業などをプログラムで効率化  

実務を通じて技術を身につけてきたため、新しい技術や既存の担当範囲外のコードにも、実際に手を動かしながら対応してきました。  

## 主な実績

- PHP8への移行に伴う既存コードの調査・修正、WordPressを用いたHP改修  
- Pythonによる約750ページの巡回監視自動化（1巡約30分）  
- 課題管理票10件の調査・実装をワンオペで担当（リリース作業を除く）  

## 個人開発

### [mgmg-crafting-tool](https://github.com/p4n8k6/mgmg-crafting-tool)
React / TypeScriptを使用した装備品の鍛冶計算ツール。既存のC#実装を再利用し、データ構造や計算処理を整理して開発。  
昔、自らC#で個人制作した残骸をChatGPTでReact化させ、調整することで鍛冶の機能は製作期間2日  
合計制作時間を10〜18時間程度に短縮。  

### [file-transfer-tool](https://github.com/p4n8k6/file-transfer-tool)
Python / Tkinterを使用したファイルコピー支援ツール。Linux環境で利用することを目的に開発。  
私の現在のメインPCがZorin OSのため、exeで配布されているファイル転送のフリーソフトは使えない。  
それが動機で自分用に作成したもの。  
公開用に機能を調整した。
